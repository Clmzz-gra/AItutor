# 语法 - 学科全景

> 定位：把零散语法规则串成一张可导航的体系网。
> 教材：Larry 语法课（语法体系主体 / 时态 / 虚拟语气 / 补语）。
> 学生起点：几乎全是薄弱点、不成体系——所以本学科**先建体系，再填细节**。

## 核心洞察（这套语法的骨架）

- **词性是一切**：名词、形容词、副词 + 修饰关系，是理解句子的钥匙。
- **简单句是一切的底座**：主谓宾定状补，读懂简单句就读懂一切。
- **从句 = 连词 + 简单句**：名词性 / 形容词性 / 副词性从句，都是简单句的扩展。
- **非谓语动词和从句是一回事**：不定式 / 动名词 / 分词，是简单句的压缩。
- **时态 = 时 + 体 + 貌**：8 大时态是这三个维度的组合。

## 体系地图

- 基础层：词性（名词 / 形容词 / 副词 / 介词）到修饰关系
- 句子层：简单句（主谓宾定状补）
- 扩展层：从句（连词 + 简单句）
- 压缩层：非谓语动词（不定式 / 动名词 / 分词）
- 动词层：时态（时体貌）、虚拟语气
- 补充：补语
- 实践：语法分析
