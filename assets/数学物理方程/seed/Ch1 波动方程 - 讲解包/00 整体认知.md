# 00 整体认知 — 第一章「波动方程」讲解包

> 定位：这一章要解决什么问题？整套讲解包怎么读？

## 对象是什么

本章研究**波动方程**（wave equation）——描述"振动如何在介质中传播"的一类偏微分方程。偏微分方程（partial differential equation，PDE）就是含有未知函数对多个自变量偏导数的方程；波动方程是其中最典型、物理背景最直观的一类，属于**双曲型方程**（hyperbolic equation，即解具有"有限传播速度"特征的方程）。

我们关心的核心对象是：一根弦、一张膜、或空间中的声波/电磁波，在给定初始状态和边界约束后，**位移 $u$ 如何随时间 $t$ 和空间位置变化**。这里的 $u$ 读作"位移函数"，$t$ 读作"时间"，空间变量 $x,y,z$ 读作"位置坐标"。

## 解决什么问题

一句话：**把"振动传播"这个物理现象翻译成数学方程，再想办法把方程解出来，并解释解的性质。**

具体拆成三个递进的问题：

1. **建模**（§1）：如何从牛顿力学把弦/膜的振动写成方程？方程本身不够，还要补上"初始状态"和"边界约束"（合称定解条件），才能唯一确定运动。
2. **求解**（§2–§4）：不同场景（无限长弦、两端固定弦、高维空间）用什么方法把解写出来？
3. **性质**（§5–§6）：解出来的波怎么传播、怎么衰减？解是否唯一、是否稳定（即输入的小误差不会导致输出的大误差）？

## 整体结构 / 路线图

```
建模（§1）──► 一维求解（§2 达朗贝尔公式）──► 有界弦求解（§3 分离变量法）
     │                    │
     │                    └──► 高维求解（§4 球平均法/降维法）
     │
     └──► 性质：传播与衰减（§5）＋ 唯一性/稳定性（§6）
```

主线叙事：**先问"方程从哪来"（§1），再问"怎么解"（§2–§4），最后问"解靠不靠谱、长什么样"（§5–§6）。** 每一步都建立在前一步之上：没有 §1 的定解条件，§2 的公式就没有输入；没有 §2 的一维解，§4 的高维解就缺少降维的跳板；没有 §5 的传播图景，§6 的能量方法就缺少物理动机。

## 核心洞察收束

> 波动方程的全部故事，就是"**有限速度传播**"这一个物理事实：扰动以速度 $a$ 沿特征线传播，而求解与性质分析（达朗贝尔公式、分离变量、能量方法）都是围绕这个事实展开的。
