# assets — 学科资产层

> 资产 = 实际产出/数据/内容（规则与资产分离）。
> 本目录**不随仓库分发实际内容**（学生个人学习内容 + 教材 OCR 不上传），仅保留占位结构。
> 学生克隆后按此结构放入自己的内容。

## 结构

```
assets/
├── {学科}/                      # 每学科一个子目录（中文名）
│   ├── seed/                    # 只读共享地基（教师/教材初始化）
│   │   ├── textbook/            # 教材（Markdown/OCR 文本，勿放版权敏感的 PDF）
│   │   ├── 学科概览.md          # 学科地图（历史/脉络/应用/关系）
│   │   └── Ch{N} {章名}.md      # 章文章（全量骨架，可选教师预置）
│   └── personal/                # 学生个人增量（新内容一律放这里）
│       ├── notes/               # 章/节/概念/思考/提问/习题/作业/问题
│       ├── papers/              # 论文 / 文献
│       ├── demos/               # 演示工具实现
│       └── profiles/            # 学习画像数据
```

## 规则

- **seed 只读**：共享地基，不写学生个人内容。
- **personal 增量**：学生所有新内容一律进 personal，不污染 seed；无 `_index.md`，治理靠目录/frontmatter/wikilink/git。
- **教材版权**：只放 Markdown/OCR 文本，不放 PDF。
