## 数学史背景

**时代**：20 世纪 30 年代—至今。

**核心问题驱动**：

1. **军事运筹的起源**：二战期间，英国为优化雷达部署、护航编队、反潜搜索等军事行动，组织科学家用数学方法分析作战问题，诞生了"operational research"（运筹学）。战后这些方法转向工业、经济与管理领域。
2. **有限资源的最优配置**：任何组织都面临"在人力、物力、财力等有限资源约束下，如何安排使目标最优"的问题——这正是运筹学的核心关切。
3. **决策的科学化**：从凭经验拍板到用数学模型+算法给出有依据的最优方案，运筹学把"决策"变成一门可计算、可验证的科学。

**关键人物**：

- **丹齐格** (Dantzig, 1914-2005)：1947 年提出**单纯形法**，线性规划成为可计算的学科，运筹学奠基性算法
- **康托洛维奇** (Kantorovich, 1912-1986)：1939 年独立提出线性规划用于计划经济，1975 年获诺贝尔经济学奖
- **冯·诺依曼** (von Neumann, 1903-1957)：对策论（博弈论）奠基人，与摩根斯坦合著《博弈论与经济行为》
- **贝尔曼** (Bellman, 1920-1984)：1950 年代提出**动态规划**与最优化原理
- **库恩、塔克** (Kuhn & Tucker)：1951 年提出非线性规划最优性条件（KKT 条件）
- **埃德蒙兹、卡普** (Edmonds & Karp)：网络流与图论算法的现代发展

**关键转折**：运筹学从"解决具体军事问题"走向"建立一般化的数学模型与算法"。线性规划（单纯形法）是第一个成熟范式，随后对偶理论、运输问题、整数规划、动态规划、图论网络、排队论、存储论、对策论、决策分析等分支相继成型，共同构成运筹学的学科版图。

## 发展脉络

```
军事运筹 (二战, 1939-1945)
    │ 雷达部署、护航、反潜——用数学分析作战问题
    ▼
线性规划 + 单纯形法 (丹齐格, 1947)
    │ 第一个成熟范式：有限资源最优配置
    ▼
对偶理论 + 灵敏度分析 (1940s-1950s)
    │ 从"求一个解"到"理解解的结构与稳定性"
    ▼
分支扩展 (1950s-1960s)
    │ 运输问题、整数规划、动态规划、图论网络、排队论、存储论、对策论、决策分析
    ▼
非线性规划 + 现代算法 (1960s-)
    │ KKT 条件、内点法、启发式方法
    ▼
计算机 + 运筹学软件 (1970s-)
    │ 大规模问题可解，运筹学进入工程与管理实践
    ▼
大数据 + 机器学习 + 运筹优化 (当代)
    │ 供应链、物流、调度、金融风控、智能决策
```

## 当代应用

| 领域 | 应用 |
|------|------|
| **供应链与物流** | 运输问题、网络流、存储论优化配送与库存 |
| **生产计划** | 线性/整数规划排产、资源分配、能力规划 |
| **交通运输** | 最短路、最大流、网络计划（关键路径）优化调度 |
| **金融风控** | 投资组合优化（非线性规划）、风险决策 |
| **通信网络** | 网络流、排队论分析流量与拥塞 |
| **人工智能/机器学习** | 优化是训练模型的核心；运筹与 ML 深度融合 |
| **军事与国防** | 资源部署、路径规划、博弈对抗 |

## 与其他科目的关系

### 前置依赖
- **线性代数**：线性规划、对偶理论、矩阵运算的基础
- **数学分析/微积分**：非线性规划、凸性、极值理论
- **概率论与数理统计**：排队论、随机型存储、风险决策

### 平行类比

| 运筹学概念 | 类比 |
|---|---|
| 线性规划 | 有限资源下的最优线性配置 |
| 对偶问题 | 从"资源约束"看问题的另一面（影子价格） |
| 动态规划 | 把大问题拆成递推的子问题 |
| 图论网络 | 用点和边建模连接与流动 |
| 排队论 | 顾客到达与服务的随机过程 |
| 对策论 | 多主体博弈的理性决策 |

### 后续延伸
- 高级优化（内点法、大规模优化、随机优化）
- 机器学习与运筹优化结合（决策智能）
- 供应链管理、运营管理、管理科学
- 博弈论进阶、机制设计

## 学习路径（应用导向，重建模与算法）

### 全局定位：这门课的统一主题

运筹学的统一主题是**"在约束下做最优决策"**。它把现实管理问题抽象成数学模型，再用算法求解，最后把解翻译回管理语言。

```
现实问题 ──→ 数学模型 ──→ 求解算法 ──→ 最优方案
   │            │            │            │
   │            └── 目标函数 + 约束条件    │
   └── 资源、需求、限制 ──────────────→ 决策与实施
```

- **建模**：把"怎么安排最好"写成目标函数和约束
- **求解**：用单纯形法、动态规划、网络流等算法找到最优解
- **分析**：对偶、灵敏度分析理解解的结构与稳定性
- **实施**：把数学解翻译回可执行的管理方案

### 三层推进逻辑

```
第一层：线性规划核心（Ch1-3）
  线性规划 + 单纯形法 → 对偶理论 → 运输问题
  运筹学最成熟、最核心的范式
  ──── 目标：掌握建模 + 单纯形法 + 对偶 ────

第二层：规划扩展（Ch4-7）
  目标规划 → 整数规划 → 非线性规划 → 动态规划
  从线性到非线性、从连续到离散、从单阶段到多阶段
  ──── 目标：理解不同问题类型的建模与算法 ────

第三层：网络与随机模型（Ch8-13）
  图与网络 → 网络计划 → 排队论 → 存储论 → 对策论 → 决策分析
  从确定型到随机型、从单主体到多主体
  ──── 目标：掌握网络优化与随机决策模型 ────
```

### 教学方式

每章按三段式展开（与 [`skills/tutor/SKILL.md`](../../.dsh/skills/tutor/SKILL.md) 的知识脉络教学法一致）：

1. **来龙**：问题驱动 + 现实场景 + 本章要解决的核心决策问题
2. **主体**：建模 → 算法 → 例题，遵循讲解质量约束（定义出发、每步有因此、先符号后数字、多视角、核心洞察收束）
3. **去脉**：当代应用 + 跨领域解读 + 高层视角 + 引发的新问题
