## 引言：勒贝格积分到底改了什么？

**一句话**：黎曼积分"竖着切定义域"，勒贝格积分"**横着切值域**"——先按函数值分组（水平集），用简单函数逼近可测函数，再取上确界。

### 需求一：黎曼积分漏掉了太多函数

狄利克雷函数（有理点取 1，无理点取 0）黎曼不可积，但它"几乎处处等于 0"——勒贝格积分给出 $\int D = 0$。**可积函数类被极大地扩充了。**

### 需求二：真正想要的是"极限与积分可交换"

逐点收敛 + 黎曼积分 ⇏ 积分收敛。三大极限定理（单调收敛、Fatou、控制收敛）给出了**交换的充分条件**，这才是勒贝格积分的核心价值。

### 需求三：重积分能否化为累次积分

Fubini 定理回答这个问题——它要求可积性（绝对可积），而黎曼意义下的累次积分定理条件要苛刻得多。

### 三步定义（本章的骨架）

```
第一步（§3.1.1）非负简单函数 φ = Σ cᵢ χ_{Eᵢ}：积分 = Σ cᵢ mEᵢ（纯加权和）
        ↓ 第二步（§3.1.1）非负可测函数 f：积分 = sup{∫φ : 0 ≤ φ ≤ f}（单调逼近）
        ↓ 第三步（§3.1.2）一般可测函数 f = f⁺ − f⁻：积分 = ∫f⁺ − ∫f⁻（正负部分开）
        ↓ 武器（§3.2）Levi / Fatou / 控制收敛：极限与积分可交换
        ↓ 对话（§3.1.3）与黎曼积分的关系；（§3.3）几何意义与 Fubini
        ↓ 推广（§3.1.4 / §3.2.3 / §3.3.2）抽象测度空间 (X, F, μ) 上的同一套理论
```

### §3.1 Lebesgue 可测函数的积分
- §3.1.1 非负可测函数的积分 —— 简单函数积分 → 取上确界；线性、单调性
- §3.1.2 一般可测函数的积分 —— 正部负部分解 $f=f^+-f^-$；可积的定义（$\int|f|<\infty$）；积分的绝对连续性

- §3.2.1 Lebesgue 积分与极限运算的交换定理 —— **单调收敛定理（Levi）**、**Fatou 引理**、**控制收敛定理（Lebesgue）**；三者互为推论的逻辑链
- §3.2.2 黎曼可积性的刻画 —— 黎曼可积 $\iff$ 不连续点集测度为零（Lebesgue 判据）
- §3.2.3 $L(X,\mathcal{F},\mu)$ 中积分的极限定理 —— 抽象测度空间上的三大定理
- 习题（p.129）

### §3.3 重积分与累次积分

- §3.3.2 测度空间上的重积分与累次积分 —— 乘积测度空间的构造与 Fubini
