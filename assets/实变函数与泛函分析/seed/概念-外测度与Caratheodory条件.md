# 概念-外测度与Caratheodory条件

> 关联：[[Sec2.1 Lebesgue 外测度与可测集]]
> 相关：[[概念-测度与黎曼积分的类比]]、[[概念-有理数与无理数集的测度]]、[[概念-可数可加性]]

## 核心结论（一句话）

**外测度是唯一"不需要任何额外结构、处处可定义"的量，且免费给出可数可加性需要的 ≤ 方向；Carathéodory 条件用"对一切集合可加分割"把 ≥ 方向也逼出来——内测度方向反了、又依赖拓扑，只能当检验工具，当不了构造起点。**

## 来龙：为什么必须"先定义、再筛选"

中心问题：把区间长度推广为 $\mathbb{R}^n$ 上"足够多集合"上的可数可加测度。难点：**不可能在全体集合上做到**（Vitali 集，见 旧版《Ch3 测度论》 §3.4），所以任何构造都是两步走：

1. **先定义**：造一个处处可定义的量；
2. **再筛选**：挑出这个量"表现良好"的集合，构成 $\sigma$-代数。

## 主体

### 1. 外测度天然是那个"处处可定义的量"

定义（§3.1）：$m^*(A) = \inf\left\{\sum_n |I_n| : A \subseteq \bigcup_n I_n\right\}$，读作"用可数多个开区间覆盖 $A$ 的最小总成本"。

- 对**任意**集合都能算——再怪的集合也总能被覆盖，成本至多是 $\infty$；
- 免费得到三条性质：非负、单调、**次可数可加**：$m^*\left(\bigcup_n A_n\right) \le \sum_n m^*(A_n)$（"≤"方向天然成立，因为覆盖并集可以共用覆盖）。

### 2. 内测度为什么当不了起点

**（a）内测度不是独立原语。** 它的定义只有两条路，都说明它是派生品：

- 借用外测度：$m_*(A) = m^*(I) - m^*(I\setminus A)$（$A$ 有界，$I$ 是包含 $A$ 的区间）；
- 借用拓扑：$m_*(A) = \sup\{m^*(K) : K \subseteq A,\ K \text{ 紧}\}$。

两条路都依赖**外测度或紧集**。内测度是"外测度 + 额外结构"的检验工具，不是新起点。

**（b）方向反了（最本质）。** 内测度满足的是**超可加性**（不相交时）：$m_*\left(\bigcup_n A_n\right) \ge \sum_n m_*(A_n)$——"≥"方向天然成立。而扩展机制（Carathéodory 扩张定理）的整个逻辑是：

> 先有处处成立的 **≤**（外测度免费给），再用条件把 **≥** 也逼出来（筛选可测集）。

内测度把 ≤ 和 ≥ 的位置颠倒了，套不进这个机制。

**（c）无界集合要先处理。** $m_*$ 对无界集合要么未定义、要么要先取极限；外测度没有这个问题（$\infty$ 自然允许）。

### 3. "内测度 + 别的条件"行不行？——行，Lebesgue 本人就这么干的

Lebesgue 1902 年原始定义：$E$ 可测 $\iff m_*(E) = m^*(E)$（**内=外**）。在 $\mathbb{R}^n$ 上完全正确，且与 Carathéodory 条件等价。问题不是"内测度路线错"，而是"它不够好"：

- **等价性证明依赖拓扑**：$m_*(E) = m^*(E) \iff \forall A:\ m^*(A) = m^*(A\cap E) + m^*(A\setminus E)$（有界情形），证明要用紧集逼近 + Heine-Borel；
- **闭包论证更绕**：证明"内=外"的集合族对可数并封闭，需要正则性夹逼，每一步都吃 $\mathbb{R}^n$ 的特殊结构；
- **不推广**：抽象空间（一般度量空间、乘积空间、无拓扑的集合）没有紧集概念，$m_*$ 根本定义不出来。

（第三种"别的条件"：$\forall\varepsilon>0$ 存在闭 $F \subseteq E \subseteq$ 开 $G$ 使 $m^*(G\setminus F) < \varepsilon$——正则性夹逼定义。同样只在 $\mathbb{R}^n$ 等价，同样不推广。）

### 4. Carathéodory 条件为什么是"对的"条件

定义（§3.2）：$E$ 可测 $\iff$ 对**一切** $A$：$m^*(A) = m^*(A\cap E) + m^*(A\setminus E)$。

- ≤ 方向自动成立（次可数可加），所以条件实质是：**任何集合 $A$ 被 $E$ 切开后，成本不损失**。$E$ 可测 ⟺ $E$ 对"尺子"透明——量 $A$ 时穿过 $E$ 的内外两部分，成本恰好相加；
- **反例（Vitali 集 $V \subseteq [0,1]$）**：$m^*(V) > 0$ 且 $m^*([0,1]\setminus V) = 1$（因为 $m_*(V) = 0$），于是 $m^*(V) + m^*([0,1]\setminus V) > 1 = m^*([0,1])$。取 $A = [0,1]$ 就发现：$V$ 把区间"切贵了"——$V$ 与 $[0,1]$ 纠缠得太碎，覆盖成本无法一致定价，这就是"不透明"；
- **为什么"对一切 $A$"而不是只对 $E$ 自己**：因为分割性质可以**传播**——若 $E, F$ 都可测，对任意 $A$ 先按 $E$ 切、再按 $F$ 切，成本逐层不损失，于是 $E^c$、$E\cap F$、可数并全都可测。这个"普遍测试"让 $\sigma$-代数闭包成为纯集合论论证（Carathéodory 定理），不需要任何拓扑；
- **副产品**：完备性免费——$m^*(N) = 0$ 的任意子集 $M$ 自动可测（因为 $m^*(A\cap M) \le m^*(N) = 0$，分割不等式自动成立）。

## 边界情况

- **条件不满足时**：$E$ 不可测 ⟺ 存在 $A$ 使 $m^*(A) < m^*(A\cap E) + m^*(A\setminus E)$（分割损失成本）。Vitali 集即此情形；
- **内测度路线的适用边界**：仅在 $\mathbb{R}^n$（有紧集 + Heine-Borel）可用；一旦进入抽象测度空间即失效；
- **外测度路线的适用边界**：不需要任何拓扑，但要求"覆盖成本"概念存在——Hausdorff 测度、乘积测度都满足。

## 去脉

- **Carathéodory 扩张定理**：环上预测度 → 外测度 → 可测集上完备测度。Lebesgue-Stieltjes 测度、乘积测度（Fubini 的前提）全是这条流水线；
- **Hausdorff 测度**：$m^s(A) = \lim_{\delta\to 0} \inf\left\{\sum_n (\operatorname{diam} E_n)^s : A \subseteq \bigcup E_n,\ \operatorname{diam} E_n < \delta\right\}$——空间连拓扑都不需要，照样外测度 + Carathéodory，分形维数就是这么定义的；
- **内测度没死**：它以**内正则性**（$m(A) = \sup\{m(K) : K \subseteq A \text{ 紧}\}$）的形式成为测度的性质，而不是定义；
- **另一条路线**：Daniell-Stone（先定义积分、再导出测度）——"测度优先"框架内 Carathéodory 最优，但框架本身不是唯一。
