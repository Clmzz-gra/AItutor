## 数学史背景

**时代**：19 世纪末—20 世纪初。

**核心问题驱动**：

1. **黎曼积分的缺陷**：狄利克雷函数 $D(x)$（有理数取 1，无理数取 0）如此简单，却在黎曼意义下不可积——极限和积分不能随便交换，可积函数太少。
2. **傅里叶级数的收敛问题**：傅里叶级数是否逐点收敛？哪些函数可以展开？这迫使数学家重新审视"函数""极限""积分"这些基本概念。
3. **无穷维空间的涌现**：微分方程、积分方程的解不是数，而是函数——需要把分析从 $\mathbb{R}^n$ 搬到无穷维。

**关键人物**：

- **康托尔** (Cantor, 1845–1918)：创立集合论，发现无穷可以分等级，对角线法
- **勒贝格** (Lebesgue, 1875–1941)：1902 年提出勒贝格测度与积分，解决黎曼积分的核心缺陷
- **巴拿赫** (Banach, 1892–1945)：1920 年代建立赋范线性空间和线性算子理论，泛函分析奠基人
- **希尔伯特** (Hilbert, 1862–1943)：积分方程研究催生了 Hilbert 空间理论
- **弗雷歇** (Fréchet, 1878–1973)：1906 年提出度量空间，统一了分析中的极限概念

**关键转折**：勒贝格发现，问题的关键不在积分本身，而在"长度"——什么样的集合有长度？这就是**测度论**的由来。先定义哪些集合"可测"、如何量其大小，再定义这些集合上的积分，一切顺理成章。

## 发展脉络

```
微积分 (17 世纪)
    │ 黎曼积分可积函数类太少，傅里叶级数收敛问题
    ▼
集合论 (康托尔, 1870s)
    │ 提供"大小""无穷"的严格工具
    ▼
勒贝格测度 + 勒贝格积分 (1902)
    │ 把积分从"竖着切定义域"改为"横着切值域"
    ▼
实变函数论 (1900–1930s)
    │ 完备的极限操作：极限与积分可交换
    ▼
抽象空间理论 (度量 → 赋范 → 内积)
    │ 把分析中的具体问题抽象为空间 + 算子的代数
    ▼
泛函分析 (1920s–1940s)
    │ 无穷维线性代数——解方程 → 算子理论
    ▼
量子力学、偏微分方程、机器学习…
```

## 郭版的两条主线（本书的选材逻辑）

郭懋正在前言中给出了这门课的骨架：**一条线是** $\mathbb{R}^n$ → $L^2$ 空间 → Hilbert 空间；**另一条平行的线是** $\mathbb{R}^n$ → $L^p$ 空间 → Banach 空间，前者是后者的特例。两条线"有合有分，有机地揉在一起"，就是全书主线：

```
        ℝⁿ（有限维欧氏空间）
        ├── L²(ℝⁿ) ──→ Hilbert 空间 ──→ Hilbert 空间上的算子
        └── Lᵖ(ℝⁿ) ──→ Banach 空间  ──→ Banach 空间上的算子
                        （p 次可积函数空间是理解两者异同的"纽结与穴位"）
```

**为什么这条主线值得记住**：它解释了全书章节顺序——Ch1–Ch3 造出 $\mathbb{R}^n$ 上的测度与积分，Ch4 把积分结果装进 $L^p$（两个方向的分岔口），Ch5 走 $L^2$ → Hilbert，Ch6 走 $L^p$ → Banach，最后回到算子。

## 当代应用

- **量子力学**：态是 Hilbert 空间中的向量，可观测量是自伴算子，谱定理是测量理论的数学基础
- **偏微分方程**：$L^p$ 与 Sobolev 空间是弱解存在唯一性的天然框架
- **概率论**：测度论是概率公理化的地基（概率 = 测度，期望 = 积分，条件期望 = 投影算子）
- **信号处理 / 图像**：Fourier 变换、卷积（Ch4 §4.3）是滤波与重建的核心工具
- **机器学习**：再生核 Hilbert 空间（RKHS）、$L^p$ 范数正则化、算子谱方法

## 学习路径建议

1. **先建骨架**：把上面的"两条主线"图记住。每一章学完，回到这张图问一句"我现在站在哪条线上"。
2. **Ch1–Ch3 是实变部分**：核心动词是"**逼近**"——用简单函数逼近可测函数、用开集逼近可测集、用连续函数逼近可测函数。抓住"逼近"两字，三章就是一件事。
3. **Ch4 是分岔口**：$L^p$ 是后面两条线的共同起点，务必吃透完备性（Riesz–Fischer）与 Hölder/Minkowski 不等式。
4. **Ch5–Ch6 是泛函部分**：核心动词是"**表示**"——Riesz 表示定理把泛函表示成内积，共轭空间理论把泛函表示成测度/序列。抓住"表示"两字。
5. **每章末尾的自测题**：各章正文第七部分是自测题，答案折叠，先自己做再看。
