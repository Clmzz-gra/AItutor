# 概念-Lp空间

- **定义**：$L^p$ 空间是"$p$ 次幂可积的可测函数"按**几乎处处相等视为同一元素**分成的等价类全体，配以范数 $\|f\|_p=\left(\int_E|f(x)|^p\,\mathrm{d}x\right)^{1/p}$（$1\le p<\infty$）或本性上界 $\|f\|_\infty$（$p=\infty$）。**读法**：$L$ 来自 Lebesgue，$p$ 是幂次；$L^p$ 读作"$L$-$p$ 空间"或"$p$ 次可积函数空间"。它是本书的**分岔口**——$p=2$ 时 $\|\cdot\|_2$ 由内积 $(f,g)=\int f\bar g$ 导出，通向 Hilbert 空间（Ch5）；一般 $p$ 时只有范数没有内积，通向 Banach 空间（Ch6）。

- **正例**：
  - $L^1[0,1]$ 就是第三章的 Lebesgue 可积函数空间——它把"可积"这一单个函数的性质升级成了"空间"这一整体结构。
  - $L^2[0,1]$ 是最有用的例子：$\|f\|_2^2=\int|f|^2$ 是"能量"，$\langle f,g\rangle=\int f\bar g$ 是"夹角余弦的分子"，于是正交、投影、Fourier 展开全部可用。
  - $L^p$ 的五个标准同类（$\mathbb{R}^n$、$C[a,b]$、$l^\infty$、$L^p[a,b]$、$l^p$）都是 Banach 空间；其中只有 $L^2$、$l^2$ 进一步是 Hilbert 空间。

- **反例**：
  - **不作 a.e. 等同就不是范数空间**：取 $E=[0,1]$、$g=\chi_{\mathbb{Q}\cap[0,1]}$，则 $\|g\|_p=0$ 但 $g\not\equiv 0$——范数公理"正定性"失效。**边界就在这里**：$L^p$ 的元素是**等价类**，不是函数本身。
  - **测度无限时包含关系全面失效**：取 $E=[1,\infty)$、$f(x)=1/x$，则 $f\in L^2(E)$ 但 $f\notin L^1(E)$；反向取 $g=x^{-1/2}\chi_{(0,1)}$ 则 $g\in L^1(0,1)$ 但 $g\notin L^2(0,1)$。所以"$L^{p_2}\subset L^{p_1}$（$p_2>p_1$）"**必须**附加 $m(E)<\infty$。
  - **$L^\infty$ 不是可分空间**：$\{\chi_{[0,t]}\}_{t\in[0,1]}$ 是不可数族且两两距离为 $1$，任何稠密集都不可数。所以"$1\le p<\infty$ 时可分"这句话在 $p=\infty$ 处断裂。
  - **一般 $p\ne 2$ 的 $L^p$ 不是内积空间**：$l^p$（$p\ne 2$）中取 $x=(1,1,0,\dots)$、$y=(1,-1,0,\dots)$，平行四边形公式不成立。$L^p$ 同理——**没有内积就没有正交，没有正交就没有投影与 Fourier 展开**。

- **边界情况**：
  - $p=\infty$ 不是"$p\to\infty$ 的极限"定义的，而是独立定义的（本性上界）；两者只在 $\lim_{p\to\infty}\|f\|_p=\|f\|_\infty$（$m(E)<\infty$）处接上。
  - **共轭指数** $\frac1p+\frac1q=1$ 中 $1$ 与 $\infty$ 配对，$2$ 与自己配对。$p=2$ 的"自共轭"是它特殊性的第一个来源。
  - **范数 vs 半范数**：$\|\cdot\|_p$ 在函数层面只是半范数（有非零函数范数为 $0$），在等价类层面才是范数。
  - **复值情形**：$L^p$ 的定义逐字不变（因为只用到 $|f|$），但复 $L^2$ 的内积必须写成 $(f,g)=\int f\bar g$，否则 $(f,f)$ 可能为负。
  - **抽象测度空间**：把 $\mathrm{d}x$ 换成 $\mu(\mathrm{d}x)$、$m$ 换成 $\mu$，全部结论平行成立，记作 $L^p(X,\mathcal{F},\mu)$。
  - **$L^p$ 与 $l^p$ 的关系**：$l^p$ 是 $\mathbb{N}$ 上计数测度对应的 $L^p$——同一套理论的两个实例。
