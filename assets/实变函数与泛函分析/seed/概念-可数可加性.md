# 概念-可数可加性

- **定义**：设 $(X,\mathcal{F})$ 是可测空间，$\mu:\mathcal{F}\to[0,\infty]$ 是集函数。若 $\mu(\varnothing)=0$，且对任意一列**两两不相交**的 $A_n\in\mathcal{F}$ 都有
  $$\mu\biggl(\bigcup_{n=1}^{\infty}A_n\biggr)=\sum_{n=1}^{\infty}\mu(A_n),$$
  则称 $\mu$ 具有**可数可加性**（也称**可列可加性**、**$\sigma$ 可加性**——"可数"读作"可以用自然数编号"，$\sigma$ 取自法语 somme，"和"）。满足这两条的 $\mu$ 就叫**测度**。
- **正例**：
  - **勒贝格测度是 $\mathbb{R}^n$ 上可数可加的**：$\mathbb{Q}\cap[0,1]$ 可数、每个单点测度为 $0$，拆成可数个两两不交的单点后
    $$m(\mathbb{Q}\cap[0,1])=m\!\left(\bigcup_{n=1}^{\infty}\{q_n\}\right)=\sum_{n=1}^{\infty}m(\{q_n\})=\sum_{n=1}^{\infty}0=0.$$
  - **计数测度**（$X=\mathbb{N}$、$\mathcal{F}=2^{\mathbb{N}}$）是可数可加的：把 $\mathbb{N}$ 拆成单点，逐个计数就是求和。
  - **Dirac 测度** $\delta_x(A)=\chi_A(x)$ 是可数可加的：可数个不交集合中至多一个含 $x$，等式两边都是 $0$ 或 $1$。
- **反例**：**"可数"两个字不能去掉——任意（不可数）无限可加必然失败。** 单点集测度为 $0$（$m(\{a\})=m([a,a])=a-a=0$）。若允许对**任意**下标集求和，则
  $$[0,1]=\bigcup_{x\in[0,1]}\{x\}$$
  是**不可数个**单点的并，逐点求和得 $\sum_{x\in[0,1]}m(\{x\})=0$，于是 $m([0,1])=0$——与正则性 $m([0,1])=1$ **矛盾**。
  **诊断**：$[0,1]$ 是不可数集，**无法**写成可数个单点之并。勒贝格的做法正是**只要求可数可加**，从而绕开这个悖论。（另一端也有反例：若把可数可加**减弱**为有限可加，则能得到"一切子集都可测"的 Banach 测度，但有限可加测度做不了任何极限定理，用处不大。）
- **边界情况**：
  - **并集必须两两不相交才有等式**。对一般的可数并，只有**次可加性** $\mu(\bigcup_n A_n)\leqslant\sum_n\mu(A_n)$。任意一列可测集的可数并仍可测，靠的是"不相交化技巧"：$\bigcup_n S_n=S_1\cup(S_2\setminus S_1)\cup(S_3\setminus(S_1\cup S_2))\cup\cdots$。
  - **可数可加性是"可测集"的特权**。外测度 $m^{*}$ 对**一切**集合都有定义，代价就是只有次可加性；只有限制到 Carathéodory 条件筛出的可测集上，$m^{*}$ 才升级为真正可数可加的 $m$。**这就是"外测度 → 筛选 → 测度"三步走的全部理由。**
  - **可数可加性直接带来两条极限连续性**：递增列 $S_n\uparrow S$ 时 $mS=\lim_n mS_n$；递减列 $S_n\downarrow S$ 时，**必须附加 $mS_1<\infty$**，否则结论失效（反例：$S_n=(n,\infty)\downarrow\varnothing$，$mS_n\equiv\infty\neq0=m\varnothing$）。这条条件在叶戈罗夫定理的证明里是关键。
  - **有限 vs $\sigma$ 有限**：$\mu(X)<\infty$ 称有限测度；$X$ 可写成可数个有限测度集之并时称 $\sigma$ 有限测度。Lebesgue 测度是 $\sigma$ 有限的（$\mathbb{R}^n=\bigcup_k[-k,k]^n$），这正是"局部研究 + 拼起来"合法的原因。
  - **与"任意无限可加"的对照**：可数可加性恰好是"能与可数极限运算和平相处"的最小强度——这也是 $\sigma$-代数必须对**可数**并封闭（而不是有限并）的原因：集合运算的规模必须与测度公理的规模配套。

## 核心洞察收束

> 可数可加性是整座测度论大厦的承重墙：它把"长度"从有限可加升级为可数可加，恰好绕开了"不可数个单点铺满 $[0,1]$"的悖论，又足以支撑全部极限运算。**一句话：可数可加 = 测度能与可数极限和平相处的最小强度；去掉它测度论就瘫，加强到不可数它立刻自相矛盾。**
