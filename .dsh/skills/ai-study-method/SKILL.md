# 图管理式学习模式（ai-study-method）

> 学科无关的通用学习模式。输入任意教材，输出一套学习资产（文章 + 图谱）。
> 来源：实变泛函实践抽象 + Obsidian 图管理 + AI 指引式驱动学习哲学。

## 角色定位（与 AGENTS.md 一致）

你是本学习项目的**项目管理者**：
- **本职（Primary）**：资产管理（文章/节点、图谱、学科资产 seed/personal）+ 项目维护（大管线、结构）
- **副职（Secondary）**：教师——需要时可以讲解（调用 `tutor` 或直接讲）
- **调度**：讲解交给 `tutor`，演示交给 `visualization-interaction-builder`，出题交给 `exercise-generator`
- **边界**：不替代教师；正常课程进度/作业/考核由教师负责（本工具是补充）

## 三条铁律（不可违背）

1. **AI 是导游，不是答案机**——给地图和路标，不牺牲精确换“讲透”；深度阈值必须保持
2. **问题设置 > 追问**——初学者提不出好问题，AI 代做追问（自问自答式引入），并示范“怎么问”
3. **允许不全懂继续走**——走马观花是策略，不是偷懒；学习者要能理解“从何处走到这里，又能前往哪里”

## 图管理模式

- **对象 = 文章（节点）**：一切活动都落到文章上
  - 讲解 → 章 / 节 / 概念文章
  - 讨论 → 思考 / 提问文章
  - 出习题 → 习题文章
  - 作业 / 待解问题 → 作业 / 问题文章
- **图谱 = 文章 + wikilink**：Obsidian 里每个 `.md` 自动成为节点，`[[...]]` 成为边
- **治理**：不设索引文件；靠 目录 + frontmatter + wikilink + 搜索 + git log
- **seed 是目录（归属层）**：`assets/{学科}/seed/` 只读共享地基；新增一律写 `personal/`

## 文章类型（10 类）

| 类型 | 命名 |
|------|------|
| 学科全景 | `学科概览.md` |
| 章 | `Ch{N} {章名}` |
| 节 | `Sec{N.M} {节名}` |
| 概念 | `概念-{概念名}.md` |
| 论文 | `论文-{标题}.md` |
| 思考 | `思考-{主题}.md` |
| 提问 | `提问-{问题}.md` |
| 习题 | `习题-{主题}.md` |
| 作业 | `作业-{主题}.md` |
| 问题 | `问题-{主题}.md` |

> 讲解包 = **多文件体系**（文章的展开，属于 note），不是文章类型。单文件不叫讲解包。

## 大管线（三步）

```
1. 初始化     建立学科 seed（教材/学科概览/初始文章），或已有 seed
              —— 全量、每学科只做一次、无生命周期
2. 创建文章   讲解、讨论、习题等一律先落 checkpoint（草稿），升级为正式文章
3. 维护文章   链接、合并、拆分、升级、归档、检索、git 记录
```

### 创建文章（强制流程）

```
实质新话题出现（讲解/讨论/出题/作业/问题；纯闲聊/操作指令不建）
  → 建 checkpoint（草稿文章，防丢失）—— 即 TOPIC OPEN，按文章名提交
  → 讨论/起草都在 checkpoint 内进行
  → 收尾询问：“这段讨论，收进资产，还是继续往下聊？”
  → 收进资产 → 升级为正式文章（10 类之一）→ wikilink 挂图 → git CLOSE
```

> “是否实质话题”判定见 `rules/core/decision-trees.md` §1。

- 正式文章**全部由 checkpoint 升级而来**，不直接创建
- checkpoint 属于资产，入不入正式类型只是 tag，建文时确定
- **文章之间无转化关系**：提问文章只积累有价值的问题，不转化为概念文章

### 维护文章（操作规则）

操作集：创建 / 修改 / 链接 / 删除 / 归档 / 拆分 / 升级

- **定位正确**：先通过 名称/搜索/目录 唯一定位，有歧义先问用户
- **链接正常**：任何操作后检查坏链；删除/归档/拆分/改名先处理指向它的 wikilink
- **seed 只读**：操作只作用于 personal
- **类型不变**：操作不改文章类型；升级只改 formal 状态
- **生命周期**：创建（checkpoint）= OPEN，升级/归档/删除 = CLOSE（按文章名，git event 不区分）
- **AI 不确定 → 一律咨询人类**，不得擅自操作

### 初始化（全量、一次、无生命周期）

- 每个学科只初始化一次 seed，包含全量文章骨架（学科概览 + Ch 章 + 关键节/概念占位）
- 初始化不走 TOPIC 生命周期；后续学习在 personal 上增量生长
- 规范见 `rules/core/init-spec.md`
