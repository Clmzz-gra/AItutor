# Exercise Generator — 习题生成

> 学科无关。参考风格：常见多元统计练习（单选 / 判断 / 填空 / 读表 / 计算 / 综合）。
> 只出题，不检验。

## 激活条件

- 用户说「出几道题」「练习一下」「出一份习题」「帮我出题」「模拟题」等
- 用户指定主题 / 章节 / 概念 / 题型 / 数量 / 难度

## 与项目规则的关系

- 产出文章类型：`习题-{主题}.md`（`rules/core/asset-spec.md` §四.8）
- 生成依赖表：`rules/core/article-generation.md`（习题行）
- 生命周期：先 checkpoint（`_checkpoints/习题-{主题}.md`）→ 用户确认收进资产 → 升级正式
- 链接：至少 1 个 wikilink 指向相关知识点 / 章 / 节 / 概念
- 命名 / frontmatter 遵循 `asset-spec.md`

## 出题原则

1. 基于用户指定知识点，不擅自拓展到无关内容
2. 知识点属于 seed 时，引用 seed 概念；题目写在 `personal/`（seed 只读）
3. 题型参考常见练习形式：
   - 单选题（含选项 + 解析）
   - 判断题（T/F + 改正 / 理由）
   - 填空题（短答案）
   - 读表题（给出表格 / 输出，问结论）
   - 计算 / 推导题（分步求解，带关键步骤）
   - 综合对比题（表格对比多个概念 / 方法）
4. 难度分层：基础 / 中等 / 易错 / 综合
5. 每题都要有折叠答案

## 答案折叠格式（强制）

使用 Obsidian callout 折叠，不要直接展开答案：

```markdown
> [!note]- 答案
> **答案**：...
> **解析**：...
```

- 整份习题的答案可以每题一个折叠块，也可以文末统一「参考答案」折叠块
- 推荐**每题紧跟题目的折叠块**，便于对照
- 如果一道题有多个小问，答案放在同一个折叠块内
- 不要写「检验 / 批改 / 判分」相关内容，不要加自动化验证流程

## 生成流程

1. 确认主题 / 范围：用户指定，或从最近学习 / 图谱推断
2. 查询相关 `seed` / `personal` 文章，提取考点与符号
3. 创建 checkpoint（`_checkpoints/习题-{主题}.md`），防丢失
4. 写作习题：
   - 标题：`# 习题-{主题}`
   - 开头：关联知识点链接
   - 正文：若干题型题目，数学公式用 LaTeX（`$...$` / `$$...$$`）
   - 每题后或文末放折叠答案
   - 结尾：考点标签 / 关联文章
5. 收尾询问：「这份习题收进资产，还是继续调整？」
6. 用户确认收进资产 → 升级为正式文章 → 挂链 → git CLOSE

## 质量要求

- 题目表述清楚，不产生歧义
- 答案放在折叠块内，默认不展开
- 答案要完整：不仅给选项 / 数值，还给出关键步骤或理由（参考常见练习的 Step / 技巧 / 易混辨析）
- 数字 / 公式必须可计算、自洽
- 不确定的题目（如教材条件缺失）先问用户，不擅自编造
