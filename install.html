安装教程

下载 ZIP → 解压 → 双击 一键安装.bat → 装 ZCode → 配免费模型 → 开始学习

📦 下载 ZIP📂 解压🪟 双击 一键安装.bat⚙️ 自动安装✅ 体检🚀 开始学习

① 准备：下载并解压

国内学生推荐用 Gitee / GitCode，避免 GitHub 需要梯子。

1

下载本项目 ZIP

点击下面任意一个仓库，进入后点页面上的 “下载 ZIP”（或“克隆/下载”按钮）把整个项目下载下来。

🇨🇳 打开 Gitee 仓库 🇨🇳 打开 GitCode 仓库 打开 GitHub 仓库

国内学生优先用 Gitee / GitCode 仓库，避免 GitHub 需要梯子。

👤 注册 / 登录：打开仓库页后，如果提示登录，先用手机号或邮箱注册并登录（免费）。登录后点 “下载 ZIP” 即可。
Gitee 仓库页：点右上角“下载 ZIP”
GitCode 仓库页：点“下载 zip”
GitHub 仓库页：点“Download ZIP”

解压到任意位置

下载得到的是一个 ZIP 压缩包。右键 → “解压到当前文件夹”（或“全部解压”），解压后会得到一个文件夹，记住这个文件夹的位置，后面所有操作都在这个文件夹里进行。

💡 解压后请确认文件夹里有 一键安装.bat、体检.bat、install.html 这些文件，说明解压成功。

方式二：用 Git 克隆（适合熟悉 Git 的用户）

如果你会用 Git，也可以直接克隆仓库（任选一个源），克隆后进入文件夹即可，效果和下载 ZIP 一样：

  • GitHub：git clone https://github.com/Clmzz-gra/AItutor.git
  • Gitee：git clone https://gitee.com/clmzz/AItutor.git
  • GitCode：git clone https://gitcode.com/clmzz/AItutor.git

克隆完成后，用 cd AItutor 进入项目文件夹，再继续下面的步骤（双击 一键安装.bat 等）。

💡 之后想更新到最新版，在项目文件夹里运行 git pull 即可。

② 一键安装（Windows）

双击一个文件，自动装好 Git / Python / Obsidian / MinerU CLI，装完自动体检。

2

双击根目录的 一键安装.bat

打开刚才解压出来的文件夹，找到 一键安装.bat，双击它即可。全程不需要输入任何命令。

找到这个 一键安装.bat，双击它
🔒 注意：浏览器无法运行安装程序。 请务必用文件管理器（“此电脑”/“我的电脑”）打开文件夹后双击 一键安装.bat，不要在浏览器里点它。

脚本会自动做这些事

  • 检查并安装 Git（没有就自动装）
  • 检查并安装 Python（没有就自动装）
  • 检查并安装 Obsidian（依次尝试 winget → choco → scoop → 浏览器手动下载）
  • 安装 Obsidian（CLI 需在下一步手动启用）
  • 安装 MinerU CLI（教材 OCR / PDF 转 Markdown，依次尝试 清华/阿里/中科大/豆瓣/官方 多个源）
  • 装完自动运行体检（doctor）

安装过程中会看到什么

会弹出黑色命令行窗口，显示安装进度。第一次安装可能需要几分钟，请耐心等待，不要中途关掉窗口。如果某个软件装不上，脚本会自动换别的源/渠道，或提示你手动下载，不会一直卡住。

正在自动安装（黑色命令行窗口）
💡 若提示“是否允许更改设备”，点 “是” 即可。若杀毒软件询问，选择“允许/信任”。

③ 启用 Obsidian CLI（手动）

Obsidian 装好后，还需要手动开启命令行界面（CLI），AI 才能读写你的笔记。

3

开启 Obsidian 命令行界面

打开 Obsidian，进入 设置 → 关于 → 命令行界面（Command line interface），按提示注册 / 启用，然后重启终端（或重启 Obsidian）。

💡 中文界面路径：设置 → 关于 → 命令行界面；英文：Settings → General（部分版本为 About）→ Command line interface。

验证是否成功

打开命令行（终端），输入下面命令，能输出命令列表就说明成功了：

  • obsidian help — 输出命令全表即成功
  • obsidian version — 显示版本号（如 1.13.7）
设置 → 关于 → 命令行界面（Obsidian 1.13.7）
📷 截图占位 2：obsidian help 验证成功（图片放 assets/install/step3-2.png）

④ 安装 ZCode（默认推荐）

ZCode 最简单，原生读取 AGENTS.md，配置最少。

4

去官网安装 ZCode

点击下面按钮打开官网，下载并安装 ZCode（安装后重开终端/命令行即可生效）。

打开 ZCode 官网
ZCode 官网：点“立即下载 ZCode”
安装后打开 ZCode 的主界面
🧩 适配多种 AI 工具（harness）：本项目同时适配 ZCode / Claude Code / Codex / Trae / dsh 等，默认推荐 ZCode（最简）。如果你已经熟悉 GitHub 或其它工具，也可以直接用你熟悉的那个，装好后重开终端即可，本项目不做检测。
💡 已经装了其它工具？ 如果你已装好 Claude Code / Codex / Trae / dsh 等，也可以直接用它们开始，无需再装 ZCode。

⑤ 配置免费模型

默认免费模型：GLM-4.5-Flash（免费，能力有限）。

5

第一步：注册 / 登录并申请免费 Key

打开 open.bigmodel.cn，用手机号或邮箱注册并登录（免费），然后在控制台申请一个 API Key（免费，只需申请一次）。

第二步：在 ZCode 里添加供应商并填写模型

在 ZCode 的 模型设置 里，先添加供应商，再按下表填写模型字段：

模型设置 → 添加供应商，填入 Base URL / API Key / 模型
编辑模型配置：填模型 ID / 上下文 / 最大输出

全部 [OK] 后即可开始。

6

运行体检

一键安装结束会自动体检；也可以随时双击根目录的 体检.bat。

看到全部 [OK] 就说明环境没问题。

开始学习

在 ZCode 里打开本项目文件夹，对 AI 说：“开始学习〈学科名〉”（例如“开始学习概率论”）。

AI 会自动建 checkpoint 快照、把讲解/讨论/习题写成文章、按“初始化 → 创建文章 → 维护文章”驱动学习，并沉淀为正式资产。

常见问题

  • 双击 一键安装.bat 没反应？ 右键 → “以管理员身份运行”；若被系统拦截，点“更多信息 → 仍要运行”。
  • MinerU 装不上？ 脚本会依次尝试 清华/阿里/中科大/豆瓣/官方 多个源，一般总有一个能成功。
  • Obsidian 超时？ 脚本会依次尝试 winget → choco → scoop → 浏览器手动下载，不会卡住。
  • 输出乱码？ 已统一 UTF-8 编码，正常 Windows 下应显示正常。
  • ZCode 没检测到？ 脚本不做检测，直接去官网安装即可，装好重开终端。
  • 浏览器点链接变成下载/打不开？ 浏览器不能运行安装程序，请用文件管理器打开文件夹后双击 一键安装.bat。
  • 体检有 [FAIL]？ 按体检提示操作（如重开 Obsidian、重开终端），再重新双击 体检.bat。
