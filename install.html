④ 配置免费模型

默认免费模型：GLM-4.5-Flash（免费，能力有限）。

4

在 ZCode 里填写模型字段

字段填写值
名称智谱 GLM-4.5-Flash
Base URLhttps://open.bigmodel.cn/api/paas/v4
API Key你在 open.bigmodel.cn 申请的 Key
API 格式OpenAI（不要选 Anthropic）
模型 IDglm-4.5-flash
上下文窗口128000
最大输出 Token96000
输入/输出类型文本（Text）为主
⚠️ 这是免费模型，能力有限：适合日常问答、学习推进、常规讲解；复杂长文本、深度推理建议改用更强（付费）模型。
查看详细配置

常见问题

  • MinerU 装不上？ 脚本会依次尝试 清华/阿里/中科大/豆瓣/官方 多个源。
  • Obsidian 超时？ 脚本会依次尝试 winget → choco → scoop → 浏览器手动下载。
  • 输出乱码？ 已统一 UTF-8 编码，正常 Windows 下应显示正常。
  • ZCode 没检测到？ 脚本不做检测，直接去官网安装即可。
  • 浏览器点“打开安装向导”变成下载？ 浏览器不能运行安装程序，请直接双击 安装向导.hta。
