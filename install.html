AItutor 一键安装教程

下载 ZIP → 解压 → 双击 一键安装.bat → 配免费模型 → 开始学习

准备：下载并解压

1

下载本项目 ZIP

国内学生推荐用 Gitee 或 GitCode，避免 GitHub 需要梯子。

GitHub 下载 Gitee GitCode
📷 截图占位：下载 ZIP 并解压（图片放 assets/install/step1.png）

一键安装

2

打开项目文件夹，双击 一键安装.bat

什么都不用输入，脚本会自动装好：Git、Python、Obsidian、Obsidian CLI、MinerU CLI，装完还会自动运行体检。

🪟 打开安装向导（推荐，可直接运行）

推荐点“打开安装向导”，它会以本地程序方式运行，能直接打开文件夹、运行 bat；若浏览器提示下载，请选择“打开/运行”，或直接双击项目里的 安装向导.hta。

📷 截图占位：打开文件夹后双击 一键安装.bat（图片放 assets/install/step2.png）
💡 若 MinerU 或 Obsidian 装不上，脚本会自动换多个源/渠道，或提示你浏览器手动下载，不会一直卡住。

安装 ZCode（默认推荐）

3

去官网安装 ZCode

ZCode 最简单，原生读取 AGENTS.md。

打开 ZCode 官网
📷 截图占位：ZCode 官网安装页（图片放 assets/install/step3.png）

配置免费模型

4

默认免费模型：GLM-4.5-Flash

在 open.bigmodel.cn 申请一次 Key，填 Base URL + Key + 模型名即可。

  • Base URL：https://open.bigmodel.cn/api/paas/v4
  • 模型名：glm-4.5-flash
  • API 格式：OpenAI（不要选 Anthropic）
查看详细配置
📷 截图占位：ZCode 里填模型配置（图片放 assets/install/step4.png）

体检 & 开始学习

5

体检通过后即可开始

一键安装结束会自动体检；也可随时双击根目录 体检.bat。

全部 [OK] 后，对 AI 说：“开始学习〈学科名〉”。

📷 截图占位：体检结果全 OK（图片放 assets/install/step5.png）

常见问题

  • MinerU 装不上？ 脚本会依次尝试 清华/阿里/中科大/豆瓣/官方 多个源。
  • Obsidian 超时？ 脚本会依次尝试 winget → choco → scoop → 浏览器手动下载。
  • 输出乱码？ 已统一 UTF-8 编码，正常 Windows 下应显示正常。
  • ZCode 没检测到？ 脚本不做检测，直接去官网安装即可。
