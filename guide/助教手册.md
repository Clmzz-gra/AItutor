# 助教手册

> 助教支持学生使用 AI 学习法。

## 职责
- 帮助学生配置环境
- 解答工具使用问题
- 每周抽查学生文章/图谱与 git 话题
- 收集反馈给老师

## 每周任务
1. 查看学生 `personal/` 增量文章与图谱
2. 抽查文章质量（结构是否符合 `asset-spec.md`，链接是否正常）
3. 用 `git log --grep "[TOPIC"` 看话题开合情况
4. 汇总常见问题

## 技术支持
- 环境问题：参考 `guide/学生使用指南.md`；一键安装用 `tools/setup/README.md`
- 环境/仓库体检：`python tools/doctor.py`
- 免费模型默认配置：`guide/免费模型配置.md`
- 工具问题：联系项目维护者
