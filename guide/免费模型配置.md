# 免费模型配置（学生端）

> 目标：**配置简单、免费、token 消耗少**。
> 适用于 AItutor 学生端（中文学习）。推荐免费 API + 各 harness 接入方式 + 省 token 策略。
>
> **AItutor 学生默认 = 智谱 GLM-4.5-Flash（能力最强的免费档，完全免费）**。学生只需申请一次 Key，把 Base URL / Key / 模型名填进 harness 即可开始学习，无需充值。

## 推荐方案

| 方案 | 费用 | 中文 | 配置难度 | 适合 |
|------|------|------|---------|------|
| **智谱 GLM-4.5-Flash**（首选：免费档中能力最强） | **完全免费** | 强 | 低 | 学生默认 |
| **智谱 GLM-4-Flash（旧免费档）** | **完全免费** | 强 | 低 | 兼容/更保守的备选 |

> 三者都是 **OpenAI 兼容 API**，配置方式统一：Base URL + API Key + 模型名。

---

## 详细信息：智谱 GLM-4.5-Flash（免费档中能力最强，推荐）

### 1. 申请 Key
1. 打开 https://open.bigmodel.cn/（智谱 AI 开放平台）注册/登录。
2. 进入「API Key 管理」，创建一个 Key（复制保存）。
3. GLM-4.5-Flash 模型**长期免费**，无需充值。

### 2. 配置参数
| 项 | 值 |
|----|-----|
| Base URL | `https://open.bigmodel.cn/api/paas/v4/` |
| 模型名（官方当前版） | `glm-4.5-flash` |
| API Key | 上面申请的 Key |

> 说明：智谱官方文档中当前免费档中能力最强的是 **GLM-4.5-Flash**，模型标识为 `glm-4.5-flash`（见 [GLM-4.5-Flash 官方文档](https://docs.bigmodel.cn/cn/guide/models/free/glm-4.5-flash)）。
> 端点统一走 OpenAI 兼容 `https://open.bigmodel.cn/api/paas/v4/`，`Authorization: Bearer <API Key>`。
> 若你的客户端/集成暂不支持 `glm-4.5-flash`，可退回旧免费档 `glm-4-flash-250414` 或 `glm-4-flash`（见方案一兼容说明）。

### 3. 在 harness 中接入
- **ZCode（默认推荐，最简）**：ZCode 原生读取 `AGENTS.md`，免额外指针文件（官网 https://zcode.z.ai/）；模型接入按其设置填 OpenAI 兼容的 Base URL / Key / 模型名即可（具体以 ZCode 官方设置为准）。
- **Claude Code**：设置环境变量
  ```bash
  export ANTHROPIC_BASE_URL=https://open.bigmodel.cn/api/paas/v4/
  export ANTHROPIC_AUTH_TOKEN=<你的GLM Key>
  export ANTHROPIC_MODEL=glm-4.5-flash
  claude
  ```
- **Codex**：Codex 设置里填 OpenAI 兼容端点（Base URL + Key + 模型名）。
- **通用（DeepTutor 等）**：Settings → Models → 添加 LLM，填 Base URL / API Key / 模型名。

### 4. ZCode 填表速查（GLM-4.5-Flash）

| ZCode 字段 | 填写值 |
|-----------|--------|
| 名称 | `智谱 GLM-4.5-Flash` |
| Base URL | `https://open.bigmodel.cn/api/paas/v4` |
| API Key | 你在 open.bigmodel.cn 申请的 Key |
| API 格式 | **OpenAI（OpenAI Chat Completions）**，不要选 Anthropic Messages |
| 模型 ID | `glm-4.5-flash` |
| 上下文窗口 | `128000` |
| 最大输出 Token | `96000` |
| 输入类型 / 输出类型 | 一般选 **文本（Text）**；是否支持图片等多模态以官方文档为准 |

> 官方文档：https://docs.bigmodel.cn/cn/guide/models/free/glm-4.5-flash
> 注意：智谱端点是 OpenAI 兼容，**API 格式必须选 OpenAI**，否则 `/v1/messages` 无法正确对接。

## 省 Token 策略

> 免费 ≠ 无限。GLM-4-Flash 虽免费，但仍有速率/用量限制；以下是 AItutor 已内建 + 建议的省 token 手段。

### 已内建（项目自带）
1. **指针注入**：入口（`AGENTS.md`/`CLAUDE.md` 等）只放指针，不注入全量规则 → 大幅省每轮 token。
2. **按需加载**：五阶段管线只读需要的文件，不一次性灌入全部规则。
3. **ZCode 原生注入**：直接注入 `AGENTS.md` 指针，不复制全文。

### 使用建议
1. **精简指令**：对话指令简短明确，AI 只读必要文件。
2. **分步学习**：一次推进一个小节，不一次性生成整章讲解包。
3. **用便宜/免费模型做常规**：日常问答/推进用 GLM-4-Flash，长文本生成（讲解包）再用强模型。
4. **控制输出长度**：需要摘要时明确"简短回答"。
