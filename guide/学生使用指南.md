# 学生使用指南

> 用 AI 学习法辅助《概率论与数理统计》学习。

## 环境准备（学生只需少量设置）
1. 克隆本项目；一键装好缺失环境（可选推荐）：Windows 跑 `tools/setup/bootstrap.ps1`，macOS/Linux 跑 `tools/setup/bootstrap.sh`。
2. 安装 AI harness：**默认推荐 ZCode**（最简单，原生读 `AGENTS.md`）；也可选 Claude Code / Codex / Trae / dsh。装好后重开终端。
3. 配置**默认免费模型 GLM-4.5-Flash**（免费档中能力最强、完全免费，只需申请一次 Key），见 `guide/免费模型配置.md`。
4. 可选：运行 `python tools/doctor.py` 自检，看是否缺东西、怎么修。

## 开始学习
- 对话："开始学习概率论"
- 或："学习第 N 章" / "讲讲 XX 概念"

## 学习流程（大管线）
1. 初始化：已有 seed，或 AI 基于教材全量初始化（每学科一次）
2. 创建文章：讲解/讨论/习题先落 checkpoint，确认后升级为正式文章
3. 维护文章：链接、修改、拆分、归档、删除由 AI 按规则执行，不确定会问你

## 常见操作
| 你想 | 说 |
|------|-----|
| 开始 | "开始学习概率论" |
| 继续 | "继续"（AI 从 git log 找未闭合话题） |
| 查某次讲解 | "我之前学的 XX 在哪" |
| 复习 | "复习第 N 章" |
| 收进资产 | "收进资产"（checkpoint → 正式文章） |

> 没有进度表/索引文件；学习形状看 Obsidian 图谱，生命周期看 git log。
