# 学生使用指南

> 用 AI 学习法辅助《概率论与数理统计》学习。

## 环境准备（学生只需少量设置）
1. 下载 ZIP 并**解压**；Windows 学生只需**双击项目根目录的 `一键安装.bat`**即可自动装好环境（macOS/Linux 跑 `tools/setup/bootstrap.sh`）。
2. 安装 AI harness：**默认推荐 ZCode**（最简单，原生读 `AGENTS.md`；官网 https://zcode.z.ai/，一键安装脚本只提供官网链接、不做检测）。也可选 Claude Code / Codex / Trae / dsh。装好后重开终端。
3. 配置**默认免费模型 GLM-4.5-Flash**（免费档中能力最强、完全免费，只需申请一次 Key），见 `guide/免费模型配置.md`。
4. 体检：一键安装结束会自动运行；也可双击根目录 `体检.bat` 或运行 `python tools/doctor.py`，看是否缺东西、怎么修。

## 开始学习
- 对话："开始学习概率论"
- 或："学习第 N 章" / "讲讲 XX 概念"

## 学习流程（大管线）
1. 初始化：已有 seed，或 AI 基于教材全量初始化（每学科一次）
2. 创建文章：讲解/讨论/习题先落 checkpoint，确认后升级为正式文章
3. 维护文章：链接、修改、拆分、归档、删除由 AI 按规则执行，不确定会问你

## 常见操作
| 你想 | 说 |
|------|-----|
| 开始 | "开始学习概率论" |
| 继续 | "继续"（AI 从 git log 找未闭合话题） |
| 查某次讲解 | "我之前学的 XX 在哪" |
| 复习 | "复习第 N 章" |
| 收进资产 | "收进资产"（checkpoint → 正式文章） |

> 没有进度表/索引文件；学习形状看 Obsidian 图谱，生命周期看 git log。

## 保持同步（建议）
> 项目会**间歇性更新新功能**（新学科包、工具、演示等）。建议**经常从上游同步本项目**，以获取最新能力与修复：
- 用 Git 同步：`git pull`（保留你的 `personal/` 增量，只同步规则/seed/工具等公共内容）
- 用 ZIP 更新：重新下载最新压缩包，把 `personal/` 复制过去（注意先备份自己的增量）
- 同步后跑一次 `体检.bat`（`python tools/doctor.py`）确认环境与图谱健康
