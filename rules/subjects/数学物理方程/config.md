# 数学物理方程 — 学科配置

> 学科规则：学习依赖 + 思考方式（非课程对应）。

## 学习依赖
| 依赖 | 说明 |
|------|------|
| 前置知识 | 数学分析、线性代数、常微分方程、复变函数（部分） |
| 符号系统 | LaTeX（偏微分算子、定解问题、Green 函数等） |
| 工具依赖 | Obsidian、Python（numpy/scipy 数值与符号） |
| 表达规范 | 建模 → 定解问题 → 求解 → 适定性分析 |

## 思考方式
- 模式：物理建模 → 数学定解 → 求解方法 → 适定性/物理解释
- 特征：三类典型方程（波动/热传导/调和）为主线，方法为工具
- 派生偏好：先讲物理背景，再讲数学推导；强调边界/初始条件

## 教学约定
- 每个方程先给物理来源 + 定解条件
- 每种解法给适用条件 + 反例
- 检验：能写出定解问题，能判断方法适用性
