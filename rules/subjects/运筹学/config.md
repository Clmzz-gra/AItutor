# 运筹学 - 学科配置

> 学科规则：学习依赖 + 思考方式（非课程对应）。
> 课程层面的教学约定见 `curriculum.md`（老师开课前写）。

## 学习依赖

| 依赖 | 说明 |
|------|------|
| **前置知识** | 线性代数（矩阵/线性方程组）、数学分析（微积分/极值）、概率论与数理统计（随机过程/分布） |
| **符号系统** | LaTeX（$x_j$、$c_j$、$a_{ij}$、$\min$、$\max$、$\sum$…） |
| **工具依赖** | Python、NumPy、SciPy、LINGO/MATLAB（求解）、Obsidian |
| **表达规范** | 建模语言（目标函数 + 约束）+ 自然语言读法（如 $\min$ 读作"最小化"） |

## 思考方式

- **模式**：建模-求解-分析 式思维（应用导向）
- **特征**：
  - 先建模（把现实问题写成目标函数 + 约束），再选算法求解，再分析解
  - 算法驱动（单纯形法、动态规划、网络流、分支定界）
  - 从具体到抽象（从实际管理问题到数学模型）
  - 强调"为什么这样建模"（来龙：现实约束 → 数学模型）
- **派生偏好**：
  - 讲解：先建模再求解、每步有"因为"、例题验证
  - 检验：建模题 + 算法步骤默写 + 应用场景识别

## 教学约定（由思考方式派生）
- 新模型首次出现必须说明现实背景 + 建模思路
- 算法步骤必须配例题演示
- 强调"为什么需要这个模型"（来龙：现实决策问题 → 数学模型）
