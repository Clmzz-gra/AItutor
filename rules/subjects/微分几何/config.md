# 微分几何 — 学科配置

> 学科规则：学习依赖 + 思考方式（非课程对应）。

## 学习依赖
| 依赖 | 说明 |
|------|------|
| 前置知识 | 数学分析、线性代数、拓扑基础、常微分方程 |
| 符号系统 | LaTeX（流形、切空间、联络、曲率等） |
| 工具依赖 | Obsidian、Python（sympy/plotly 可视化） |
| 表达规范 | 几何直观 + 坐标计算 + 抽象定义并用 |

## 思考方式
- 模式：几何直观 → 坐标计算 → 抽象定义 → 整体性质
- 特征：先看图形/例子，再形式化；局部与整体结合
- 派生偏好：讲解先给几何直觉，再给公式推导；反例/退化情形强制

## 教学约定
- 新符号首次出现必须定义 + 自然语言读法
- 每个定理给几何意义 + 证明思路
- 检验：能画出/描述几何对象，能复述证明主线
