# 高等代数 - 学科配置

> 学科规则：学习依赖 + 思考方式（非课程对应）。
> 课程层面的教学约定见 `curriculum.md`（老师开课前写）。

## 学习依赖

| 依赖 | 说明 |
|------|------|
| **前置知识** | 中学代数（多项式运算、二元/三元一次方程组、简单行列式）、解析几何（向量点积、平面与直线） |
| **符号系统** | LaTeX（$\det A$、$\operatorname{rank}A$、$A\sim B$、$A\simeq B$、$T^*$、$\dim V$、$\langle\alpha,\beta\rangle$…） |
| **工具依赖** | Python、NumPy、SymPy（符号计算）、Obsidian |
| **表达规范** | 矩阵/向量记号 + 自然语言读法（如 $\det A$ 读作"A 的行列式"，$A\sim B$ 读作"A 相似于 B"） |

## 思考方式

- **模式**：**双向翻译**式思维（几何 ↔ 代数）
- **特征**：
  - **几何问题代数化**：把几何对象（子空间、变换、度量）写成矩阵与方程组，用代数工具处理
  - **代数问题几何化**：把矩阵运算读回几何（特征值 = 一维不变子空间、Jordan 块 = 链状结构）
  - **标准型驱动**：核心问题是"在所有等价的矩阵里，挑出最简的那一个"——相似（Ch7）、合同（Ch8）、正交相似（Ch9）
  - **结构化**：先问"这是什么空间上的什么映射"，再问"它的不变量是什么"
  - 从具体到抽象（$\mathbb{R}^2/\mathbb{R}^3$ → $n$ 维 → 一般数域上的抽象线性空间）
- **派生偏好**：
  - 讲解：先给几何直观再给代数定义、每步有"因为"、反例强制、矩阵与映射**成对出现**
  - 检验：计算题 + 反例构造 + 概念辨析（相似 vs 合同 vs 正交相似）

## 教学约定（由思考方式派生）

- 新概念首次出现必须同时给出**几何读法**与**代数定义**（例：特征值 = 存在一维不变子空间 ⇔ $\det(\lambda I-A)=0$）
- 每个矩阵结论要说明它在 $\mathbb{R}^2$ 或 $\mathbb{R}^3$ 里长什么样
- **三种等价关系必须显式区分**：相似 $A\sim B$（同一线性变换换基）、
  合同 $A\simeq B$（同一二次型换基）、正交相似（换标准正交基）——混用是本学科最常见错误
- Ch3（线性空间/基与坐标/过渡矩阵）是全书地基，**不允许含糊带过**
- 选学内容（§1.7、§2.7、§6.4、§7.8、§8.5、§9.7–§9.10、第十章）标注清楚，按需取舍
