# 实变函数与泛函分析 — 学科配置

> 学科规则：学习依赖 + 思考方式（非课程对应）。
> 课程层面的教学约定见 `curriculum.md`（老师开课前写）。

## 学习依赖

| 依赖 | 说明 |
|------|------|
| **前置知识** | 数学分析（极限/连续/积分）、线性代数、点集拓扑基础 |
| **符号系统** | LaTeX（$\mu$、$\sigma$-代数、$L^p$、$\mathcal{B}$…） |
| **工具依赖** | Python、NumPy、Obsidian |
| **表达规范** | 严格形式化记号 + 自然语言读法（如 $\forall$ 读作"对任意"） |

## 思考方式

- **模式**：定义-定理-证明 式思维（高度公理化）
- **特征**：
  - 先严格定义（可测集/测度/可测函数），再陈述定理，再证明
  - 公理化/形式化推理（$\sigma$-代数、$\sigma$-可加性）
  - 反例驱动（条件不可少，如可测性条件）
  - 抽象层次高（从具体到抽象，如黎曼→勒贝格）
- **派生偏好**：
  - 讲解：先定义再使用、每步有"因为"、反例强制
  - 检验：动机复述题 + 证明思路默写 + 反例构造

## 教学约定（由思考方式派生）
- 新符号首次出现必须定义 + 自然语言读法
- 定理条件不可少的反例必须给出
- 强调"为什么需要抽象"（来龙：黎曼积分的局限 → 勒贝格积分）
