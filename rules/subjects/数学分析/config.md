# 数学分析 - 学科配置

> 学科规则：学习依赖 + 思考方式（非课程对应）。
> 课程层面的教学约定见 `curriculum.md`（老师开课前写）。

## 学习依赖

| 依赖 | 说明 |
|------|------|
| **前置知识** | 初等数学（函数/三角/不等式/数列初步）、集合与映射的初步语言 |
| **符号系统** | LaTeX（$\varepsilon$-$\delta$、$\lim$、$\forall/\exists$、$\sup/\inf$、$\sum$…） |
| **工具依赖** | Python（SymPy/NumPy，做数值验证与可视化）、Obsidian |
| **表达规范** | 严格形式化记号 + 自然语言读法（如 $\varepsilon$-$\delta$ 读作"艾普西龙-德尔塔"） |

## 思考方式

- **模式**：定义-定理-证明 式思维（**从直观到严格**，与实变的"高度公理化"不同）
- **特征**：
  - 先给几何/物理直觉，再严格化：极限的 $\varepsilon$-$N$、$\varepsilon$-$\delta$，确界原理、一致收敛
  - **极限是唯一主线**：数列极限 → 函数极限 → 连续 → 导数 → 积分 → 级数
  - **量词的顺序与依赖**是全部难点的源头（$\forall\varepsilon\exists\delta$ 谁依赖谁）
  - 反例驱动：条件不可少（如"连续 ⇏ 一致连续"、"逐点收敛 ⇏ 一致收敛"）
  - **归结原则（海涅定理）**把函数极限与数列极限打通，是学科内第一座关键桥
- **派生偏好**：
  - 讲解：先直观后严格、每步有"因为"、$\varepsilon$ 语言逐层翻译（把"对任意 ε"翻成"你随便给一个 ε"）
  - 检验：定义复述题 + $\varepsilon$ 语言翻译 + 反例构造 + 证明思路默写

## 教学约定（由思考方式派生）

- 新符号首次出现必须定义 + 自然语言读法
- 定理条件不可少的反例必须给出
- 强调"为什么需要严格化"（来龙：18 世纪直观微积分的漏洞 → 19 世纪分析的算术化，Cauchy/Weierstrass）
