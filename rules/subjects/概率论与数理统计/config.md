# 概率论与数理统计 — 学科配置

> 学科规则：学习依赖 + 思考方式（非课程对应）。
> 课程层面的教学约定见 `curriculum.md`（老师开课前写）。

## 学习依赖

| 依赖 | 说明 |
|------|------|
| **前置知识** | 微积分、集合论基础 |
| **符号系统** | LaTeX（$\mathbb{P}$、$\mathbb{E}$、$\sigma$-代数…） |
| **工具依赖** | Python、NumPy、SciPy、Obsidian |
| **表达规范** | 形式化记号 + 自然语言读法（如 $\forall$ 读作"对任意"） |

## 思考方式

- **模式**：定义-定理-证明 式思维
- **特征**：
  - 先严格定义，再陈述定理，再证明
  - 公理化/形式化推理
  - 反例驱动（条件不可少）
- **派生偏好**：
  - 讲解：先定义再使用、每步有"因为"、反例强制
  - 检验：动机复述题 + 证明思路默写

## 教学约定（由思考方式派生）
- 新符号首次出现必须定义 + 自然语言读法
- 定理条件不可少的反例必须给出
- 检验回路含"明天能讲给别人听"验收
