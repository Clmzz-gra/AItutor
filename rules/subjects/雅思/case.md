# 案例：雅思（IELTS）

> 图管理式学习模式的落地案例：雅思备考学科包。
> 方法论参考 StudyHelper（`E:\StudyHelper\skills\ielts\SKILL.md`），
> 长期只使用：**听读回抄法、串词成文、引导精读/扫盲式阅读**。

## 教材 / 材料

- 剑桥雅思真题系列（Cambridge IELTS）
- 外刊文章（每日约 200 词）
- 其他适合精读的英文材料

## 长期学习方式

### 1. 听读回抄法

1. **读**：读一篇约 200 词的外刊/短文，标出 3-5 个目标词汇/表达
2. **听**：听音频，重点听目标词/表达的发音与连读
3. **回抄**：抄写包含目标词/表达的句子
4. **口头造句**：用目标词口头造句
5. **写 1 句**：把口头句中的 1 句写下来

> 同一批词汇/表达经过 读 → 听 → 回抄 → 口头造句 → 写，同时练阅读、听力、写作、口语。

### 2. 串词成文

- 当积累了一批生词/表达（例如来自同一篇文章或同一话题），将其串成一篇连贯短文。
- 通读短文，读不顺的地方就是薄弱词。
- 目的：用语境绑定记忆，而不是孤立背词表。

### 3. 引导精读 / 扫盲式阅读

- **引导精读**：
  - 逐段拆解：段落信息 + 语言点 + 功能
  - 可用选择题、判断题、讨论题辅助理解
  - 关注可迁移表达，但不强制进入表达练习流程
- **扫盲式阅读**：
  1. 选一篇未读过的 IELTS 真题 Passage 或同等短文
  2. 先扫清生词（可分级：核心词汇/阅读词汇/其他）
  3. 再从头通读，顺畅即过关
  4. 核心 + 阅读词汇建议不超过 40 个

## 不做什么

- 不追踪进度：无 `progress.json`、`trends.json`、周报、会话统计。
- 不主动启用 StudyHelper 中的表达练习、观点库、段落写作、错误记录等核心流程。
- 不要求固定写作/口语评分体系。
