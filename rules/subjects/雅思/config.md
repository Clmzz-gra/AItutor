# 雅思 - 学科配置

> 学科规则：学习依赖 + 思考方式（非课程对应）。
> 方法论参考 StudyHelper（`E:\StudyHelper\skills\ielts\SKILL.md`），
> 但**长期只启用三种核心方法**：听读回抄法、串词成文、引导精读/扫盲式阅读。
> 其他 StudyHelper 核心方法默认静默，不主动触发；不追踪学习进度。

## 学习依赖

| 依赖 | 说明 |
|------|------|
| **前置知识** | 基础英语词汇、基本语法、常见学术话题背景 |
| **语料来源** | 外刊文章（约 200 词起）、剑桥雅思真题/Passage |
| **工具依赖** | Obsidian、音频/视频播放器、词典；需要抓外刊时可用 browser-harness |
| **表达规范** | 英式/美式拼写统一；注意拼写、时态、单复数 |

## 思考方式

- **长期不变的三条主线**：
  1. **听读回抄法**：读 → 听 → 回抄 → 口头造句 → 写 1 句，让同一批表达同时过听说读写。
  2. **串词成文**：一批生词/表达出现后，不零散背，串成一篇连贯短文通读。
  3. **引导精读 / 扫盲式阅读**：
     - 引导精读：与 AI 或老师逐段拆解，理解段落信息、语言点和功能。
     - 扫盲式阅读：独立自学，先按三级词汇扫清生词，再通读全文。
     - 逐段标记-讲解：学生先标记卡住的词/句，AI 逐段讲解并写入资产（详见 `studyhelper-method.md` §5）。

## 教学约定（由思考方式派生）

1. 所有练习围绕上述三种方法进行，不引入额外的表达库/观点库/段落写作流程。
2. 其他 StudyHelper 核心方法（表达练习、观点构建、段落写作、错误记录、周报等）**静默**，不主动触发，也不出现在日常流程中。
3. **不追踪进度**：不做 `progress.json`、`trends.json`、学习周报、会话统计等进度追踪。
4. 每篇外刊/真题的产出可简单落在 `personal/reading/` 与 `personal/notes/`，但只作为内容积累，不做统计。
5. 写作/口语的即时反馈可以做，但不用固定模板和评分体系。
