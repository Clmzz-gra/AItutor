# 语法 - 学科配置

> 学科规则：学习依赖 + 思考方式（非课程对应）。
> 教材：Larry 语法课（语法体系主体 / 时态 / 虚拟语气 / 补语）。

## 学习依赖

| 依赖 | 说明 |
|------|------|
| **前置知识** | 基础词汇量、能读简单句 |
| **语料来源** | Larry 语法课教材（语法体系主体、时态 1、虚拟语气 1-3、补语） |
| **工具依赖** | Obsidian、词典、句子分析练习材料 |
| **表达规范** | 例句用规范英语；语法术语首次出现附中文解释 |

## 思考方式

- **体系优先**：语法不是零散规则的堆叠，而是一张网。
  - 词性（名词 / 形容词 / 副词）+ 修饰关系 = 理解句子的钥匙。
  - 简单句（主谓宾定状补）是一切的底座。
  - 从句 = 连词 + 简单句。
  - 非谓语动词和从句是一回事。
  - 时态 = 时 + 体 + 貌。
- **还原到简单句**：任何复杂句都能拆回「主谓宾定状补」的简单句。
- **规则靠例句验证**：语法点必须配正例 + 反例，能自己造句才算掌握。

## 教学约定（由思考方式派生）

1. 先建体系，再填细节：每讲一个点，先说明它在体系里的位置（来龙）。
2. 每个语法点必须配「正例 + 反例」。
3. 优先用「句子分析」检验：给一个句子，能否拆出主谓宾定状补、识别从句 / 非谓语。
4. 不孤立背规则；规则要用例句和自造句子固化。
5. 学生自述「几乎全是薄弱点、不成体系」——因此**体系框架优先于细节**。
